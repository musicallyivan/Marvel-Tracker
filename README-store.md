# Marvel Tracker para Microsoft Store

Este proyecto ya está preparado para convertirse en una PWA y ser empaquetada como app Windows para Microsoft Store usando herramientas como PWABuilder o un empaquetado MSIX compatible con Windows.

## Requisitos previos

- Un certificado de firma para Windows
- Una cuenta de Microsoft Partner Center
- Una app con identidad y descripción final
- Iconos y capturas para la Store

## Archivos preparados

- manifest.webmanifest
- service-worker.js
- assets/icons/
- index.html con metadata PWA

## Siguiente paso recomendado

1. Instalar la app en el navegador como PWA para comprobar la instalación.
2. Generar el paquete MSIX con PWABuilder.
3. Firmar el paquete con el certificado de la app.
4. Subir el paquete a Partner Center.
5. Añadir política de privacidad, capturas, iconos y descripción final.
