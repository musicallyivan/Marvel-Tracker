# ⚡ MARVEL TRACKER · MCU (Universo Cinematográfico de Marvel)

> **El tracker definitivo para seguir todas las películas y series del Universo Cinematográfico de Marvel (MCU) en orden cronológico perfecto.**

![MARVEL TRACKER Banner](https://image.tmdb.org/t/p/w500/rQKabpeIewLLNStFr3anEXI0xqu.jpg)

---

## 🌟 Características Principales

- ⚡ **Orden Cronológico Cancónico & Fecha de Estreno**: Todo el catálogo de más de 58+ películas, series y especiales del MCU ordenados desde *Capitán América: El primer vengador* (1943) hasta *Avengers: Secret Wars* (2027).
- 🖼️ **Generador de Ficha de Fan en Tiempo Real (HTML5 Canvas)**: Renderiza una imagen PNG de alta resolución con tus estadísticas de progreso, porcentaje completado y parrilla visual (borde verde + tick para las vistas, candado para las pendientes).
- 🍿 **Calculadora de Maratón MCU**: Calcula si llegarás a tiempo para el próximo estreno de cine (*Avengers: Doomsday*, *Fantastic Four*, *Thunderbolts**, etc.) según tu ritmo diario de visionado.
- 🏆 **Sistema de Logros e Insignias**: Desbloquea medallas de oro al completar etapas como la *Saga del Infinito*, *Iniciativa Vengadores*, *Guardián Cósmico*, *Maestro Místico* o *Leyenda del Multiverso*.
- 👥 **Modo Versus entre Fans**: Compara tu avance pantalla a pantalla con tus amigos importando su copia de seguridad.
- 🎬 **Rutas Guiadas Especiales**: Filtra por maratones temáticos (*Ruta Esencial Doomsday*, *Saga de Loki*, *Saga de Spider-Man*, *Solo Películas*).
- 🔊 **Efectos de Sonido & Modo Cine**: Audio sintetizado en tiempo real con Web Audio API y atenuación de pantalla para ver tráileres.
- 📅 **Exportación a Calendario (.ics)**: Descarga las fechas de estreno oficiales para sincronizarlas con Google Calendar o Apple Calendar.
- ⭐ **Valoraciones y Notas Personales**: Califica de 1 a 5 estrellas y guarda reseñas privadas en cada título.
- 💾 **Copia de Seguridad JSON**: Exporta e importa tus datos en cualquier momento. 100% privado, guardado en `localStorage`.

## 🚀 Cómo Ejecutar Localmente

### Opción 1: Ejecución Directa
Abre el archivo `index.html` directamente en tu navegador web preferido (Chrome, Firefox, Edge, Safari).

### Opción 2: Servidor Local (Recomendado)
Ejecuta el archivo ejecutable incluido `Abrir-Marvel-Tracker.bat` o inicia un servidor HTTP de Python/Node:

```bash
python -m http.server 8080
```
Luego navega a `http://localhost:8080`.
