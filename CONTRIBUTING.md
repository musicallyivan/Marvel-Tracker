# Guía de Contribución · MARVEL TRACKER

¡Gracias por tu interés en contribuir a **MARVEL TRACKER**! 🎉

Este proyecto es una aplicación web impulsada por la comunidad de fans del Universo Cinematográfico de Marvel.

---

## 🛠️ ¿Cómo puedes colaborar?

### 1. Reportar Errores o Erratas (Issues)
Si encuentras alguna errata en las fechas de estreno del MCU, un tráiler que no cargue o un fallo visual:
- Abre un **Issue** en GitHub explicando brevemente el problema.
- Incluye capturas de pantalla si es un error visual.

### 2. Proponer Nuevas Películas / Series
Cuando Marvel Studios anuncie un nuevo título o cambie una fecha de estreno oficial:
- Puedes enviar un **Pull Request** modificando el array `entries` en `app.js`.

### 3. Enviar Cambios (Pull Requests)
1. Haz un **Fork** de este repositorio.
2. Crea una rama para tu característica: `git checkout -b feature/nueva-caracteristica`.
3. Haz tus cambios y verifica que no existan errores de sintaxis (`node -c app.js`).
4. Haz un commit de tus cambios: `git commit -m 'Añade nueva característica'`.
5. Haz Push a tu rama: `git push origin feature/nueva-caracteristica`.
6. Abre un **Pull Request** detallando tus mejoras.
